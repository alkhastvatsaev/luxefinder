## Indexation

1. Deploy Vercel
2. Sitemap : `https://luxefinder.app/sitemap.xml` (guides + hubs EU inclus)
3. Bing : `npm run indexnow`
4. Google : GSC → resoumettre sitemap ; P0 dans `docs/seo/URLS_TO_SUBMIT.txt`
5. Export : `npm run seo:export-urls` → `URLS_ALL.txt`
